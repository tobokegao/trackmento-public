- **`[ua]` の実測（2026-09-14）で `/s/*` の人以外アクセスの71% が「プレビュー」だった**（Xなどのリンクカード生成）。

- **正規表現の `\b` は日本語の文字も単語の一部として扱う**（2026-10-01、ホームページ担当のセッションでの実例）。
  Pythonの `re` はUnicodeの英数字を単語の文字と見るので、「TTを」の `TT` は `\bTT\b` に合わない。英字の境目だけを見たいときは
  `(?<![A-Za-z])TT(?![A-Za-z])` と書く。JSの `\b` はASCIIだけを単語の文字と見るので合う。**二重実装で `\b` を使うとPythonとJSで結果が分かれる**
- **Windowsのシェルに日本語や込み入ったスクリプトを直接渡さない**（2026-10-01、VJ担当・ホームページ担当のセッションの両方で起きた）。

- **Bandcampの曲名には幅ゼロの空白（U+200B）が混じることがある**（同上）。TRACKMENTOでは確かめたうえで対応不要とした。
  重複を消すときは `merge.py` の `_STRIP_RE`（`\W`）で取り除かれ、描くときは `_drawable` がフォントに無い文字として落とす
