# 曲名・アーティスト名の蛇足を外す

2026-09-21

## 何を直すか

曲が多い並びで、**ジャケットより文字のほうが主役になっている**。

利用者の共有（`843a31ecb431`「思い出深い東方アレンジ100曲」10x10・16:9・曲名リスト付き）で、
マスの塊は出力の **18.5%** しかない。残りは曲名の流し込み。

原因は曲名の長さ。YouTubeとニコニコ動画から取り込んだ題は動画のタイトルそのままなので、
分類のタグ・媒体の表記・チャンネル名の尾が全部入っている。

```
【東方Vocal／Traditional Rock】「心綺楼」「凋叶棕」【ENG Subs】 / Kappashiro
【東方ボーカル】【凋叶棕】どうして... / MaribelUsami
リバースイデオロギー / KISIDA KYODAN & THE AKEBOSI ROCKETS - Topic
```

100曲で曲名＋アーティスト名が **5,421字**（1曲あたり平均54字、最長122字）。

`_wrap_plan` は「出力での文字を `FLOW_MIN_FONT`（20px）に固定し、入る枠をいちばん小さくする」で
割り付けを決めるので、**文字が多いほど枠が広がり、塊が相対的に小さくなる**。曲数と曲名の長さに
上限がないため、この構造では文字量が増えるほどジャケットが小さくなり続ける。

## 何をするか

曲名とアーティスト名から、**確実に蛇足だと言える部分だけ**を外す。

### 決めたこと

- **表示の変換1本にする**。純関数 `trim(title, artist) -> (title, artist)`。
  マスに入っているデータ（`grids/*.json` のcells）は元のまま。表示するところが全部この関数を通る
- **既定で効く**。optionsの `trimNames` が既定true。設定で外すと元の題に戻る
  （データは元のままなので、いつでも往復できる）
- **画面と書き出しの両方で同じ形にする**。片方だけ刈ると「画面と出力が違う」になる
- **確定ボタンも置く**。「すべての曲名を短くする」で刈った結果をデータに書き戻す。
  刈り方が気に入らないところを、そのあと編集パネルで手直しできる（書き戻さないと、
  手直しの対象が元の長い題のままになる）

### 刈る規則（4つ）

括弧は同じ種類どうしで対にする（`【】` `［］` `[]` `〔〕` `《》`）。既存の
`backend/sources/vocadb.py` の `_TITLE_BR` と同じ考え方。

#### R1媒体・字幕の表記

括弧の中身が**媒体語だけ**のとき、括弧ごと外す。括弧に入っていない末尾の同じ語も外す。

```
(?:Full\s*|Short\s*|Long\s*)?(?:M/?V|P/?V|Music\s*Video|Lyric\s*Video|Official\s*(?:Music\s*)?Video
|Official\s*Audio|Visualizer|Audio|Teaser|Trailer|Live\s*Video)
|(?:ENG\s*)?Sub(?:s|bed|title[ds]?)?|字幕(?:付き?)?|歌詞(?:付き?)?
|Full\s*ver\.?|Short\s*ver\.?|(?:公式|Official)\s*(?:MV|PV|Video)
```

例: `【MV】` `[Music Video]` `【ENG Subs】` `【FullMV】` `… / 魂音泉 [Music Video]`

#### R2チャンネル名の尾（アーティスト名）

アーティスト名の**末尾**にある、YouTubeが作るチャンネル名の尾を外す。1つ外したらまた見る（最大3回。
`… Official YouTube Channel` のように重なることがある）。

```
\s*(?:[-–—]\s*Topic|Official\s*(?:YouTube\s*)?Channel|公式\s*(?:YouTube\s*)?チャンネル
|(?<!\w)VEVO|Channel|チャンネル)\s*$
```

例: `KISIDA KYODAN & THE AKEBOSI ROCKETS - Topic` → `KISIDA KYODAN & THE AKEBOSI ROCKETS`、
`Adust Rain Official YouTube Channel` → `Adust Rain`

#### R3分類・区分のタグ（曲名）

括弧の中身に**分類語**を含むとき、括弧ごと外す。

```
Vocal|ボーカル|ヴォーカル|アレンジ|arrange|ニコカラ|カラオケ|歌ってみた|演奏してみた|踊ってみた
|公式|Official|M/?V|P/?V|Music\s*Video|Lyric\s*Video|Sub(?:s|bed)?|字幕|歌詞付|Full\s*ver
|初音ミク|MMD|音MAD|実況
```

**「東方」単独は分類語に入れない**。入れると `【東方紅魔郷・東方花映塚】`（原作名）や
`【東方ダンマクカグラ】`（作品名）まで消える。`【東方Vocal】` `【東方ニコカラ】` は
`Vocal` `ニコカラ` の側で引っかかるので取りこぼさない。

#### A1アーティスト名の繰り返し

`_ / ／ | ｜ ・ ･` と前後に空白のある `-` で割り、**全要素の正規化が同一**なら1つにする。

`ytr_ytr` → `ytr`。要素が違えば触らない（`qfeuille3_v2 🥐⚓` は `qfeuille3` と `v2 🥐⚓` で別物なのでそのまま）。

#### A2宣伝の文句を含む要素を落とす

アーティスト名を区切り（`/ ／ , 、 ， | ｜`、前後に空白のある `-`）で割り、
**宣伝の文句を含む要素を捨てる**。全部落ちるなら何もしない。

```
発売中|販売中|配信中|通販|予約|受付中|好評|新譜|NEW\s*(?:ALBUM|SINGLE|SONG)|最新|
公開中|投稿中|更新中|チャンネル登録|Subscribe|公式(?:サイト|ストア|通販)|Store|
毎週|毎月|毎日|活動中|始めました
```

例: `アンノウンX公式チャンネル / 東方ダンマクカグラ発売中` → `アンノウンX公式チャンネル`
（そのあとR2が `公式チャンネル` を外して `アンノウンX`）

#### G題からアーティスト名を移植する

**次の3つがすべて立ったときだけ**、題の中の名前をアーティスト名にする。

- **G1** アーティスト欄にA2の宣伝の文句がある（＝チャンネル名であって名前ではない）
- **G2** アーティスト欄のどの要素も、題の中に出てこない（出てくるなら名前として妥当）
- **G3** 題に `/` がちょうど1つ。後半から作品名の括弧（`『』「」【】[]（）`）と
  末尾の `テーマ曲` `主題歌` `挿入歌` `OP` `ED` `イメージソング` `より` `収録` を落とし、
  R1〜R4を通して2字以上残る

例:

```
題    : 「幻想に咲いた花」MV FULL ver./岸田教団&THE明星ロケッツ×草野華余子『東方ダンマクカグラ』テーマ曲
作者欄: アンノウンX公式チャンネル / 東方ダンマクカグラ発売中
→ 岸田教団&THE明星ロケッツ×草野華余子
```

**判定は刈る前の元の名前で行う**。先にR2が `公式チャンネル` を外すとG1が立たなくなる。

順番は **G（移植）→ A1 → A2 → R2**。

#### R4曲名の中のアーティスト名の重複

アーティスト欄を区切り（`/` `／` `,` `、` `，` `|` `｜` 前後に空白のある `-`）で割った名前の集合を作り、

- 括弧の中身がその1つと一致するなら、括弧ごと外す（`【ビートまりお】` でアーティスト欄が
  `ビートまりお / COOL&CREATE`）
- 曲名の末尾の `/ 名前` `- 名前` がその1つと一致するなら、その部分を外す（最大2回）

突き合わせは正規化してから（`backend/merge.py` の `_n()` と同じ規則）。

### 順番

G（移植）→ A1 → A2 → R2 →（ここまでアーティスト名）→ R1・R3・R4の括弧（左から1回で見る）→
R1の末尾 → R4の末尾。

括弧を外したあとに末尾を見るので、`… / 幻音録【人形裁判/不思議の国のアリス】` のように
括弧が後ろに付いていてもR4が効く。

### 安全弁

- 刈った結果が正規化して **2字未満**なら刈らない（`_n(s)` の長さで見る）
- アーティスト名が空になるなら刈らない
- 曲名が丸ごと消えるなら刈らない

### 実測（`843a31ecb431` の100曲、16:9・2000px出力）

| | 文字数 | 1マス | 塊の面積比 | 組み方 |
| --- | --- | --- | --- | --- |
| 刈り前 | 5,421字 | 64px | 18.5% | 回り込み |
| 刈り後 | 4,019字（74%） | 88px | 34.3% | 回り込み |

マスの一辺が **1.37倍**、面積が **1.85倍**。95/100マスが変わる。
規則ごとの件数はR3が109、R2が22、R1が16、R4が10。

アーティスト名の規則（A1・A2・G）は、**みんなの並び40件・782曲**で2件だけ発動した。
どちらも正しく、誤爆は0件。

## どこに置くか

### 新しいファイル

- `backend/names.py` … `trim(title, artist)` と語のリスト。`merge.py` の `_n()` を借りる
- `frontend/index.html` の `trimName()` … 同じ規則をJSで。**二重実装が1つ増える**

### 効く場所

| どこ | 何を直すか |
| --- | --- |
| 画面のマスの帯・拡大表示・曲名リストのプレビュー | `trimName()` を通す |
| `renderShareCanvas`（ブラウザ描画） | 曲名リストとマスの帯 |
| `backend/render.py` | `_flow_rows` / `_row_plan` / `_sidebar` などが読む曲名。**割り付けを決める前**に刈る |
| `backend/share.py` の共有ページの曲リスト・OG画像 | 同上 |
| `cli.py` の `list` / `render` / `share` | 表示と描画 |

刈るのは**割り付けを決める前**。刈ったあとの文字で行数・字の大きさを決めないと、
枠が縮まずに効果が出ない。

### 設定

- `GridOptions` に `trimNames: bool = True`（`backend/grids.py`）。グリッドJSONと共有JSONに入る
- 書き出し設定に「曲名の蛇足を外す」チェック1つ。4種はまとめる（OS 9風の画面に4つ並べると重い）
- `cli.py` に `--trim` / `--no-trim`

### 確定ボタン

並べ替えの下に「すべての曲名を短くする」。押すと
「84マスの曲名・52マスのアーティスト名を短くします。よろしいですか？」と件数を出して確認 →
cellsに書き戻す。取り消しは1回ぶん持つ（`applyData` の履歴と同じ仕組み）。

## 突き合わせ

`scripts/compare_trim.py` を足す。`compare_layout.py --tracks` が使っている題の一覧を読み、
Pythonの `names.trim()` とChromiumで動かした `trimName()` の出力が**全件一致する**ことを見る。
1件でも違えば失敗にする（曲名が変われば折り返しが変わり、割り付けが丸ごとずれる）。

`scripts/compare_render.py` にも、刈り込みを入れた組を1つ足す。

## 画面と文書

- 固定文字を足すので `scripts/build_fonts.py` → `scripts/upload_fonts_r2.py` と
  `scripts/check_i18n.py` を回す（`EN` 表に英語を足す）
- `frontend/index.html` を変えるので `scripts/build_app.py` → `scripts/upload_app_r2.py`
- `backend/pages.py` の `CHANGES` に1行（手順はスキル `/updates`）
- `docs/layout.md` に「刈り込みは割り付けの前」を、`docs/ui.md` に設定の場所を書く
- `CLAUDE.md` の「二重実装の一覧」に `names.py` ↔ `trimName()` を足す

## やらないこと

- `（Vo:あよ）` `(歌唱senya)` の歌唱者表記は外さない（曲の情報）
- `【原曲：…】` `【幻想万華鏡14話EDテーマ】` は外さない（原曲名・作品名）
- `※閲覧注意` のような注記は外さない（判断が分かれる）
- 取り込みのときに刈ることはしない（元の題が失われる）
